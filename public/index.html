un-proxy patterns:
Missing @ / www records
A * wildcard does NOT cover the apex — a zone with only * leaves @ unresolvable. Finds zones missing @ (mirror from *, else www) or missing www with no wildcard (mirror from @), probing the source first so you never clone a dead value. Zones with nothing to mirror get clone-candidate recommendations.
Un-proxy records by pattern
Finds proxied (orange-cloud) records whose name contains the pattern, across every Cloudflare zone, and flips them to DNS-only. Mail-infrastructure hostnames (pm-bounces, dkim, mail…) must not be proxied.
Source-truth IP audit
Pairs every A/AAAA record by name across Enom and Cloudflare and flags any whose IPs differ — the "cloned record got the wrong IP" detector. Note: for domains already cut over, Enom may be legitimately stale if you've since changed IPs in Cloudflare.
Shared-IP audit
Lists IPs used by A/AAAA records across multiple zones. Shared hosting is normal — but an IP appearing on a domain it shouldn't is how wrong-data clones show themselves. Informational; nothing is changed.
Fix misplaced DMARCs fleet-wide
Finds v=DMARC1 policies published at dmarc.domain (no underscore — invisible to mail receivers) where no _dmarc.domain exists, and mirrors them to the correct name. Originals are left untouched.
